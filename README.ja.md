# assume-nothing

**AIは「思い込まない」と約束した。これでもう、思い込めない。**

Claude Code 用のプラグインです。AIに「動く前に必ず見る」をさせます。

1. **最初に下調べ**：会話が始まると、パソコンと作業フォルダを調べて、「確認済み」「入っていない」「不明」に分けた短い一覧をAIに渡します。
2. **下調べが無ければ道具は使えない**：下調べが済むまで、AIの道具の使用をすべて止めます。止めた理由と一緒に下調べの結果を返すので、AIはそれを読んで続けられます。
3. **入っていないコマンドは実行させない**：入っていないコマンドを実行しようとしたら、実行前に止めて、代わりに入っているものを伝えます。

[English](README.md)

## なぜ作ったか

Karpathy 氏の考えをまとめた `CLAUDE.md` のような指示書は、AIに「書く前に考えろ」「思い込むな」とお願いします。ただのお願いなので、AIが読み飛ばすことがあります。

フック（AIの外側で動く仕組み）なら読み飛ばせません。`assume-nothing` は「思い込むな」を、お願いから仕組みに変えます。

下調べに意味があることを示す研究もあります。[Meta-Harness 論文](https://arxiv.org/abs/2603.28052)（Stanford ほか、2026年）では、AIの動かし方を自動で改良していった結果、「最初の一手の前に環境の一覧を渡す」という改良が見つかりました。Terminal-Bench 2 という試験で、Claude Opus 4.6 では 74.7% → 76.4%、Claude Haiku 4.5 では 33.7% → 37.6% でした。下調べが無いとき、AIは最初の2〜4手を「何が入っているか探る」ことに使っていたそうです。ただし論文は下調べだけを外した比較をしていないので、参考値として見てください。

## 入れ方

Claude Code で次の2行を実行し、新しい会話を始めます。

```text
/plugin marketplace add kajisho5/assume-nothing
/plugin install assume-nothing@assume-nothing
```

## しないこと

- 「許可」は出しません。いつもの確認画面はそのままです。
- ファイルの中身、環境変数の値、パスワードは読みません。名前と有無だけを記録します。
- どこにも送信しません（`deep net` は、AIが頼んだときだけ github.com・pypi.org・registry.npmjs.org に接続確認を送ります）。
- 中で何かが壊れたら、黙って通します。AIが動けなくなることはありません（止め続けたい場合は `ASSUME_NOTHING_STRICT=1`）。
- 安全のための壁ではありません。フックを通らない道具もあります。

## 設定

プロジェクトで必ず使う道具は、作業フォルダの `.assume-nothing.json` に書くと、最初の下調べで確認されます。

```json
{ "tools": ["blender", "ffprobe", "wrangler"] }
```

## 動く環境

- Mac・Linux（amd64 / arm64）、Windows は Git Bash がある場合
- ほかのソフトは不要です（Go で作った実行ファイル1つ）
